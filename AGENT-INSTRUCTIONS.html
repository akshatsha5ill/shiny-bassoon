2. What the deliverable is

Each assignment is a single self-contained HTML page that looks like handwritten blue-ink text on ruled notebook paper, with a red margin rule, words drifting between three close pens (section 6), and prints cleanly to A4.

3. Standard workflow

  1. Get the content. ChatGPT share links will not load — they need JavaScript and only return the title. Ask the user to paste questions and answers as text.
  2. Read source files. .docx is a ZIP: unzip word/document.xml and strip tags. Scanned .pdf has no text layer — extract the embedded JPEGs and read them as images.
  3. Reuse the template from experiment-05.html. Do not restyle from scratch.
  4. Add pen variation. Paste the script from section 6 before </body>. Never hand-split words into spans — the script is the single source of truth.
  5. Write the HTML, then verify (section 8).
  6. Deliver and tell the user how to print.

Why line-height: 32px matters

The rules repeat every 32px. Text line-height must equal 32px and the sheet padding must be a multiple of 32px, or every line drifts off its rule. Block spacing should also be multiples of 32 (use margin: 32px 0 0 0, not 16px).

Why top: 7px matters

Handwriting fonts have large ascender space, so text baseline lands above the rule and looks like it is floating. Shifting every text block down 7px seats it on the line. If it still looks off on the user's screen, nudge to 9px — do not remove it.

6. Pen variation — split words across similar hands

Handwriting is not one typeface. Real script drifts in slant, size and spacing several times inside a single word. Reproduce that cheaply: break each eligible word into 2–3 chunks and give each chunk a different pen.

User's wording: each set of letters is written from a different yet similar font. Neighbouring chunks must differ, but never enough to look like two authors.

The pens are derived from the approved font

All three pens are the same face (Wraith Ink) with a small affine change, so they can never clash:

↑ The same word cut into three chunks, one pen each. The difference is deliberately small.

Do not mix the other TTFs

Measured against Wraith, Victor's ascenders are 29% shorter and its descenders 41–51% shorter; Gloria's x-height is 25% larger. Mixed families read as a collage, not as one hand. A second family may join the pool only if x-height, cap-height, ascender and descender all land within about 8% of Wraith's.

The algorithm

A runtime script, pasted once before </body>. It never edits the source text by hand, so the same page always renders the same way.

  1. Walk every text node in .sheet; skip pre, code, h1, h2, h3, .title and anything marked data-no-split.
  2. Eligible word = /^[A-Za-z][A-Za-z'’-]*$/ and at least 4 letters. Numbers, formulas, e-mail addresses and variable names are left whole.
  3. Seed = FNV-1a hash of the word, XORed with the page seed and the word's index, fed to a mulberry32 PRNG. Deterministic: reload and print match exactly.
  4. 40% of eligible words split (SPLIT_RATE = 0.40); the rest stay whole. That restraint is what makes it look natural.
  5. Split into 2 chunks; 25% of words with 6+ letters get 3 (THREE_WAY = 0.25).
  6. Cut points keep every chunk at 2+ letters (MIN_CHUNK = 2).
  7. Pens are drawn without replacement, so neighbouring chunks — and all chunks in one word — always differ.
  8. Each chunk also gets its own micro-jitter: rotate ±0.5°, shift ±0.7px, scale 0.99–1.01 on top of its pen's own scale. That is what stops identical pens from looking identical.
  9. If JavaScript is off, the page is plain text — still correct, just uniform.

Tuning

ConstantDefaultEffect
SPLIT_RATE0.40share of eligible words split
THREE_WAY0.25chance a 6+ letter word uses 3 pens
MIN_CHUNK2shortest allowed piece
SEED0x5f356495change per assignment for a different cut pattern

Keep the defaults unless the user asks. Never raise SPLIT_RATE above ~0.6 — every word splitting reads as a ransom note, not handwriting.

Script (paste before </body>)

<script>
/* Pen variation: split prose words into 2-3 chunks, each in a different pen.
   Deterministic - the same text + seed renders identically on reload and print. */
(function () {
  var SPLIT_RATE = 0.40;   // share of eligible words that get split
  var THREE_WAY = 0.25;    // chance that a 6+ letter split uses 3 chunks
  var MIN_CHUNK = 2;       // never leave a one-letter piece
  var SEED = 0x5f356495;   // one seed per assignment
  var WORD = /^[A-Za-z][A-Za-z'\u2019-]*$/;

  function hash(s) {
    var h = 2166136261;
    for (var i = 0; i < s.length; i++) {
      h ^= s.charCodeAt(i);
      h = Math.imul(h, 16777619);
    }
    return h >>> 0;
  }

  function rng(seed) {
    return function () {
      seed = seed + 0x6D2B79F5 | 0;
      var t = Math.imul(seed ^ seed >>> 15, 1 | seed);
      t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
      return ((t ^ t >>> 14) >>> 0) / 4294967296;
    };
  }

  function cut(word, rnd) {
    var n = word.length;
    if (n < 2 * MIN_CHUNK || rnd() >= SPLIT_RATE) return [word];
    var k = n >= 3 * MIN_CHUNK && rnd() < THREE_WAY ? 3 : 2;
    var cuts = [], c;
    if (k === 2) {
      cuts.push(MIN_CHUNK + Math.floor(rnd() * (n - 2 * MIN_CHUNK + 1)));
    } else {
      c = MIN_CHUNK + Math.floor(rnd() * (n - 3 * MIN_CHUNK + 1));
      cuts.push(c);
      cuts.push(c + MIN_CHUNK + Math.floor(rnd() * (n - c - 2 * MIN_CHUNK + 1)));
    }
    var parts = [], last = 0;
    for (var i = 0; i < cuts.length; i++) {
      parts.push(word.slice(last, cuts[i]));
      last = cuts[i];
    }
    parts.push(word.slice(last));
    return parts;
  }

  function pens(k, rnd) {
    var pool = [1, 2, 3];
    var out = [];
    while (out.length < k) out.push(pool.splice(Math.floor(rnd() * pool.length), 1)[0]);
    return out;
  }

  function build(word, seed) {
    var rnd = rng(seed);
    var parts = cut(word, rnd);
    if (parts.length < 2) return null;
    var names = pens(parts.length, rnd);
    var wd = document.createElement('span');
    wd.className = 'wd';
    parts.forEach(function (part, i) {
      var s = document.createElement('span');
      s.className = 'chunk';
      s.setAttribute('data-pen', names[i]);
      s.style.setProperty('--rot', (rnd() * 1.0 - 0.5).toFixed(2) + 'deg');
      s.style.setProperty('--dy', (rnd() * 1.4 - 0.7).toFixed(2) + 'px');
      s.style.setProperty('--sc', (0.99 + rnd() * 0.02).toFixed(3));
      s.textContent = part;
      wd.appendChild(s);
    });
    return wd;
  }

  var sheet = document.querySelector('.sheet');
  if (!sheet || sheet.querySelector('.chunk')) return;

  var walk = document.createTreeWalker(sheet, NodeFilter.SHOW_TEXT, null);
  var nodes = [], n;
  while ((n = walk.nextNode())) nodes.push(n);

  var index = 0;
  nodes.forEach(function (node) {
    var el = node.parentElement;
    if (!el || el.closest('pre, code, h1, h2, h3, .title, [data-no-split]')) return;
    var text = node.nodeValue;
    if (!/[A-Za-z]{4,}/.test(text)) return;

    var frag = document.createDocumentFragment();
    text.split(/(\s+)/).forEach(function (token) {
      if (!WORD.test(token)) {
        frag.appendChild(document.createTextNode(token));
        return;
      }
      var built = build(token, hash(token) ^ SEED ^ Math.imul(index++, 2654435761));
      frag.appendChild(built || document.createTextNode(token));
    });
    node.parentNode.replaceChild(frag, node);
  });
})();
</script>

8. Before you deliver

  1. Font path resolves relative to the HTML file — keep both files in the same folder.
  2. No raw < inside <pre> blocks (use &lt;).
  3. Count <b> and <u> tags — both should be 0.
  4. Word splitting: every .wd reads back as the original word, every chunk has 2+ letters, and no two neighbouring chunks share a data-pen.
  5. No .chunk inside pre, code, h1–h3, .title or [data-no-split].
  6. Reload twice — the cut pattern must be identical (deterministic seed).
  7. If output examples are shown, verify them by hand or by running the code.
  8. Open the page, hard-refresh, and eyeball that text sits on the rules.

9. How the user prints

  1. Open in Chrome or Edge.
  2. Click the Print Assignment button in the top toolbar.
  3. Set Paper: A4 Margins: None and enable Background graphics — without it the ruled lines and red margin will not print.
  4. Print or Save as PDF.
